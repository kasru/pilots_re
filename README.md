# pilots_re

Декомпилированная игра "Братья Пилоты: По следам полосатого слона".

Это -- первая игра из серии игр с популярными персонажами
Братьями-Пилотами, известными по мультсериалу "Следствие ведут Колобки".
Сценарий игры выдержан в стиле пародийного детектива, в котором сыщики
Братья-Пилоты вынуждены искать выход из любых ситуаций, возникающих в
ходе расследования похищения слона из ЗООПАРКА. Играющему придется
решить ряд головоломок, пережить напряжение погони, окунуться в атмосферу
"триллера", пройти через серию комедийных ситуаций.

Разработчик игры: Компания GAMOS.
Права на издание и распространение игры на территории бывшего СССР
принадлежат компании "1С".
Права на персонажи игры: Московская анимационная студия "Пилот".

Восстановленный исходный код проигрывателя Game Maker из игры «Братья Пилоты: По следам
полосатого слона» (PILOTS.EXE, 1997). Код на C17 восстановлен по полностью разобранной базе IDA
и собирается MSVC.

Для работы нужны оригинальные файлы игры: данные игры дописаны в хвост оригинального `PILOTS.EXE`.

## Сборка

На этой ветке (`sdl2`) — SDL2-порт под Windows x86/x64, Linux и Nintendo Switch:

- Windows: `SRC\build_sdl.bat [debug|release] [x86|x64]` (по умолчанию `release x64`;
  x86 → `PILOT_RV.EXE`, x64 → `PILOT_RV_x64.EXE`);
  нужны Visual Studio 2022 и Windows SDK, SDL2 лежит в `third_party\SDL2`.
- Linux: CMake — `cmake -S . -B build64` (нативный x86_64) или `build32` (32-бит
  в контейнере из `Containerfile`).
- Nintendo Switch: `sh scripts/build_switch_podman.sh debug` (devkitA64 в контейнере)
  → `build-switch-dbg/PILOT_RV.nro`.

Исходная (до-SDL2) 32-разрядная реконструкция собирается батами `SRC\build.bat` (выпуск,
`build.bat debug` — отладка) и `SRC\build-vs2022.bat` (то же под VS2022) → `SRC\out\PILOTS_RE.EXE`;
её исходники новой структуры (`gm.h`, `host.c`, `vm.c`, …) пришли из ветки `main` и в состав
порта не входят. Подробности порта — в `AGENTS.md` и `SRC\docs`.

Запуск порта: положите `PILOT_RV.EXE` рядом с оригинальным `PILOTS.EXE` (и каталогом `MOVIES`)
и запустите; сохранения (`PILOTS*.SAV`, `PILOTS0.230`) совместимы с оригиналом.

## Отличия от оригинала

Поведение повторяет оригинал, включая его особенности (они отмечены в коде комментариями
«Особенность оригинала»). Сознательно изменено только то, что на современных Windows не работает
или портит память:

- буферы путей — `MAX_PATH` вместо 64–128 байт (оригинал падает, если каталог игры лежит глубоко);
- размер рамки окна считается через `AdjustWindowRectEx` (иначе клиентская область меньше 640×480);
- громкость звуков и музыки программная: `waveOutSetVolume` в современных Windows задаёт громкость
  всего приложения (выключение звуков глушило музыку), а громкость синтезатора MIDI не читается
  (кнопка «музыка» сразу выключалась);
- отпускание кнопки мыши, остановившей AVI, не доходит до игры (иначе щелчок по анимации
  проскакивал на флажок выбора уровня под ней);
- стек машины скриптов — собственный массив, а не стек x86.

Документация по устройству движка — `SRC\docs`.
