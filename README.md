# pilots_re

Восстановленный исходный код проигрывателя Game Maker из игры «Братья Пилоты: По следам
полосатого слона» (PILOTS.EXE, 1997). Код на C17 восстановлен по полностью разобранной базе IDA
и собирается MSVC.

Для работы нужны оригинальные файлы игры: данные игры дописаны в хвост оригинального `PILOTS.EXE`.

## Сборка

`SRC\build.bat` — выпуск, `SRC\build.bat debug` — отладочная сборка. Нужны Visual Studio
(MSVC x86) и Windows SDK; пути к ним заданы в начале `build.bat`. Результат — `SRC\out\PILOT_RE.EXE`.

Сборка только 32-разрядная: записи файла игры хранят 32-разрядные указатели.

## Запуск

Положите `PILOT_RE.EXE` в каталог игры рядом с оригинальным `PILOTS.EXE` (и каталогом `MOVIES`).
У собранного EXE нет хвоста с данными, поэтому он читает их из `PILOTS.EXE` в том же каталоге;
сохранения (`PILOTS*.SAV`, `PILOTS0.230`) совместимы с оригиналом.

## Отличия от оригинала

Поведение игры повторяет оригинал, включая его особенности (они отмечены в коде комментариями
«Особенность оригинала»). Всё, что менялось, — это то, что мешало играть:

- игра запускается на современных Windows (32- и 64-разрядных), Linux и Nintendo Switch —
  оригинальный `PILOTS.EXE` там не работает;
- глубоко лежащий каталог игры больше не приводит к сбою — длинные пути к файлам обрабатываются
  корректно;
- окно всегда имеет полную клиентскую область 640×480;
- кнопки «звуки» и «музыка» в панели настроек регулируют громкость независимо: выключение
  звуковых эффектов больше не глушит музыку, и громкость музыки работает исправно;
- щелчок, остановивший идущий фильм, не срабатывает на элемент игры, лежащий под ним.

Сохранения (`PILOTS*.SAV`) совместимы с оригиналом.

Помимо этого порт добавляет возможности, которых в оригинале не было:

- полноэкранный режим с сохранением пропорций картинки (`Alt`+`Enter`, см. «Горячие клавиши»);
- переключение картинки «растянуть на весь экран» ↔ «сохранить пропорции 4:3» — одна и та же
  кнопка на всех платформах: клавиша `-` на клавиатуре (Windows, Linux) или `-` на геймпаде
  (Switch);
- подсветка всех объектов, с которыми игра принимает щелчки (`Ctrl`);
- заметный индикатор загрузки сцены вместо «зависшего» экрана;
- выбор каталога с данными игры ключом `-datapath`;
- управление геймпадом на Nintendo Switch.

## Горячие клавиши

Клавиатура и мышь (Windows, Linux):

- `Alt`+`Enter` — включить/выключить полноэкранный режим;
- `-` (минус) — переключить картинку: растянуть на весь экран или сохранить исходные пропорции
  4:3; на Switch ту же роль играет кнопка `-` геймпада; из обычного окна первое нажатие сразу
  включает полноэкранный растянутый режим;
- `Ctrl` (удерживать) — белые кружки над объектами, с которыми игра принимает щелчки;
- мышь: левая кнопка — основное действие, правая — второе действие;
- щелчок по идущему фильму, `Space` или `Enter` — пропустить его;
- клавиши направления и действия задаёт сама игра (до восьми направлений и четыре особые
  клавиши).

Геймпад Nintendo Switch:

- левый стик — курсор;
- `A` — щелчок левой кнопкой мыши, `B` — щелчок правой;
- `-` (Joy-Con) — тот же переключатель картинки, что клавиша `-` на клавиатуре (Windows, Linux);
- `R` (удерживать) — подсветка объектов, с которыми можно щёлкать (как `Ctrl`);
- `X`, `Y`, `L` — не назначены.

При запуске (Windows, Linux; на консоли командной строки нет):

- `-fullscreen` — запуститься сразу в полноэкранном режиме;
- `-datapath <каталог>` — взять данные игры из указанного каталога.

Документация по устройству движка — `SRC/docs`.
