# pilots_re

Декомпилированная игра "Братья Пилоты: По следам полосатого слона".

Это -- первая игра из серии игр с популярными персонажами
Братьями-Пилотами, известными по мультсериалу "Следствие ведут Колобки".
Сценарий игры выдержан в стиле пародийного детектива, в котором сыщики
Братья-Пилоты вынуждены искать выход из любых ситуаций, возникающих в
ходе расследования похищения слона из ЗООПАРКА. Играющему придется
решить ряд головоломок, пережить напряжение погони, окунуться в атмосферу
"триллера", пройти через серию комедийных ситуаций.

Разработчик игры: Компания GAMOS.
Права на издание и распространение игры на территории бывшего СССР
принадлежат компании "1С".
Права на персонажи игры: Московская анимационная студия "Пилот".

Для работы требует оригинальных файлов игры.

Код и документация созданы ИИ Claude Code.

Адаптация под SDL2 и 64 битную платформу ИИ MiMo-V2.6-Flash.
